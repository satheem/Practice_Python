
# 🧩 Exercise (Basics + Problem Solving)


Write a **Python program** that:

1. Asks the user to enter **a list of numbers separated by commas**  
2. Finds and prints:

- The **sum of all numbers**  
- The **largest number**  
- The **smallest number**  
- The **count of even numbers**  
- The **count of numbers greater than the average**  

**Requirements**:

- Use **variables, input/output, type casting, operators**  
- Do **not** use `max()` or `min()` functions  
- Do **not** use any external libraries  


## Example Input

```

Enter numbers: 4,12,7,9,20,15

```

## Example Output

```

Sum: 67
Largest: 20
Smallest: 4
Even numbers count: 3
Numbers greater than average: 3

```
