## 🧩 Problem: Log File Analyzer 

### Scenario

You are given a list of log messages from an application.

Each log message has this format:

```
"<LEVEL>: <message>"
```

Where `<LEVEL>` can be:

* `INFO`
* `WARNING`
* `ERROR`

---

### 🎯 Task

Write a function called `analyze_logs(logs)` that:

1. Takes a list of log strings
2. Counts how many logs belong to each level
3. Returns the result as a dictionary

---

### ✅ Example

```python
logs = [
    "INFO: Application started",
    "WARNING: Low disk space",
    "ERROR: Failed to connect to database",
    "INFO: User logged in",
    "ERROR: Timeout occurred"
]

result = analyze_logs(logs)
```

**Expected output:**

```python
{
    "INFO": 2,
    "WARNING": 1,
    "ERROR": 2
}
```

---

### 📌 Professional Requirements (important)

* Use **clear variable names**
* Add a **docstring**
* Handle edge cases:

  * empty list
  * invalid log format (ignore it)
* Do **not** use external libraries
* Readability > clever tricks

---

### 🧠 Hints (think like a pro)

* You may need `split()`
* Don’t assume all logs are valid
* Initialize counts safely
