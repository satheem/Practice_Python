# 🐍 Practice_Python

A **public repository** where I solve daily Python problems to improve **logic, problem-solving skills, consistency, and coding habits**.  
Each file in this repo represents **one problem with its solution**.  
No folders, no complexity — just pure practice and progress.


## 🚀 Goal

The main goals of this repository are:

- 📝 Practice Python **every day**
- 💡 Build strong **problem-solving skills**
- 🔄 Stay **consistent with daily coding**
- 📊 Track progress using **GitHub activity and commits**



## 📂 Structure

All files are placed in the **root folder**, no nested folders.  
Each file represents a single problem:
`p001.py`
`p002.py`
`p003.py`
`...`

- Each file = **one problem**
- Naming convention: `pXXX.py` where XXX is the problem number



## 🧠 Topics I Cover

Problems will include a variety of Python topics such as:

- 🔢 NumPy
- 📊 Pandas
- ⚙️ Algorithms (sorting, searching, recursion, etc.)
- 🗂 Data Structures (lists, sets, dictionaries, stacks, queues, linked lists)
- 📁 File Handling
- 🔤 Strings & Text Processing
- 🔁 Loops & Conditional Logic
- 🏗 OOP (Classes & Objects)
- ✨ Any other Python concept I want to practice



## 🔄 How I Work Daily

    1. Pick a problem from a coding platform or create my own
    2. Write the solution in Python
    3. Save it as `pXXX.py`
    4. Commit and push the changes to GitHub

This ensures **continuous learning and daily contributions**.
