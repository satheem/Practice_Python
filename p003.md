# 🧩 CONTROL FLOW EXERCISE

Write a program that:

**📌 Task**

Ask the user to enter three numbers.

Then print:

1. The **largest**
2. The **middle** (the number that is not largest or smallest)
3. The **smallest**
4. Whether the three numbers form
    - an equilateral triangle (all equal)
    - an isosceles triangle (two equal)
    - a scalene triangle (all different)

**❌ Don’t use:**

- `max()`
- `min()`
- `sorted()`

**✔️ Use only:**

- if / elif / else
- >< ==
- and / or

**📝 Example**

Input:

```

10 20 15

```


Output:


```

Largest: 20
Middle: 15
Smallest: 10
Triangle type: scalene

```
