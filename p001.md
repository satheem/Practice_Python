 
# NumPy Array Reversal (p001)

**Problem:**
You are given a space separated list of numbers. Print a reversed NumPy array with elements of type float.

**Input Format:**
A single line of input containing space separated numbers.

**Output Format:**
Print the reversed NumPy array with type float.

**Sample Input:**

```
1 2 3 4 -8 -10
```

**Sample Output:**

```
[-10.  -8.   4.   3.   2.   1.]
```

**Reference:**

* Hackerrank Problem: [NumPy Arrays](https://www.hackerrank.com/challenges/np-arrays/problem?isFullScreen=true)
* How to reverse a NumPy array: [StackOverflow](https://stackoverflow.com/questions/6771428/most-efficient-way-to-reverse-a-numpy-array)

**Solution:**

```python
import numpy

def arrays(arr):
    # Convert input list to numpy array with float type
    arr = numpy.array(arr, float)
    # Reverse the array
    arr_reverse = arr[::-1]
    return arr_reverse

# Read input from user, split into a list
arr = input().strip().split(' ')
# Call the function
result = arrays(arr)
# Print the result
print(result)
```
